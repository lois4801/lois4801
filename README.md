## ◉ The Journey

**`2021` — Genesis.** The account opens in the last days of December. A decision to start building in public.

**`2023` — The Data Foundation.** Thirty-six repos in twelve months: SQL Server deep-dives, Power BI and Tableau dashboards, Excel pipelines, ML notebooks — housing prices, credit fraud, HVAC occupancy, NLP.

**`2024` — Industry Intelligence.** Analytics turns toward the real world — injury prevention for power companies, root-cause analysis in aviation and aerospace.

**`2026` — The Agentic Era.** Full-stack AI engineering: Lucio AI Platform, the Ember data studio, a multi-agent LangGraph system, and NEXUS — an agentic OS tying every project together.
